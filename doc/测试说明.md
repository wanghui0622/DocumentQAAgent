# 测试说明

## 1. 测试目标

针对 `data/raw/` 下两个文档，各设计 **5 道**测试题，覆盖：

- 正文/数值问答
- 表格问答
- 无答案拒答
- 跨文档隔离（限定 doc_id 检索）

| 文档 | doc_id | 类型 |
|------|--------|------|
| GBT 1568-2008 键 技术条件 | `GBT+1568-2008+键+技术条件` | 国标/技术标准 |
| agent开发作业样本 | `agent开发作业样本` | 金融财报 |

## 3. 运行方式

### 前置条件

```bash
python3 -m src.cli parse --all
python3 -m src.cli index --all
# .env 已配置可用 LLM API
```

### 执行评测

```bash
# 两个文档分别评测 + 汇总
python3 -m src.cli eval

# 仅评测国标文档
python3 -m src.cli eval --suite gbt

# 仅评测金融样本
python3 -m src.cli eval --suite agent

# 合并为一份报告（10 题）
python3 -m src.cli eval --suite combined
```

或直接：

```bash
python3 tests/eval/run_eval.py --suite all
```

### 手动验证示例

```bash
# 国标
python3 -m src.cli ask "键的抗拉强度最低要求是多少？" --doc-id "GBT+1568-2008+键+技术条件"

# 金融样本
python3 -m src.cli ask "2025年6月30日代理买卖证券款的合计金额是多少？" --doc-id "agent开发作业样本"

# 无答案（限定金融文档）
python3 -m src.cli ask "键的抗拉强度最低要求是多少？" --doc-id "agent开发作业样本"
```

## 4. 指标定义

| 指标 | 说明 |
|------|------|
| Retrieval Recall@5 | gold page/clause 是否出现在 top 检索结果 |
| Answer Accuracy | 可答题关键词/数值是否命中 |
| Citation Accuracy | 是否返回引用，且 doc_id 与目标文档一致 |
| Refusal Accuracy | 无答案题是否正确拒答 |
| Overall Pass | 单题综合判定 |

# 演示录制说明

请按以下脚本录制 **5–10 分钟**演示视频（或截图序列）。

## 准备工作

1. 将 `GBT 1568-2008 键 技术条件.pdf` 放入 `data/raw/`
2. 配置 `.env` 中的 `OPENAI_API_KEY`
3. 安装 OCR：`pip install -e ".[ocr]"`

## 录制脚本

### Part 1：部署启动（约 1 分钟）

```bash
git clone <your-repo>
cd DocumentQAAgent
python -m venv .venv && source .venv/bin/activate
pip install -e ".[ocr]"
cp .env.example .env
# 展示 .env 中 Key 已配置（打码）
```

### Part 2：PDF 解析（约 2 分钟）

```bash
python -m src.cli parse
python -m src.cli blocks --limit 5
```

展示要点：
- PDF 类型为 `scanned`
- blocks 中含 `clause` 与 `table` 类型
- 表1 Markdown 内容

### Part 3：索引构建（约 30 秒）

```bash
python -m src.cli index --skip-parse
```

### Part 4：问答演示（约 3 分钟）

**CLI 三问：**

```bash
python -m src.cli ask "键的抗拉强度最低要求是多少？"
python -m src.cli ask "普通平键的键宽 b 尺寸公差 AQL 是多少？"
python -m src.cli ask "花键的技术要求是什么？"
```

展示：答案 / 拒答、Citations、Self Check

**Streamlit：**

```bash
streamlit run app/streamlit_app.py
```

展示解析预览 Tab + 问答 Tab 的引用与自检 JSON。

### Part 5：评测报告（约 1 分钟）

```bash
python -m src.cli eval
```

展示 Overall Pass Rate、Refusal Accuracy 等指标。

## 无 PDF 时的 Smoke Test

```bash
python -m src.cli seed
python -m src.cli ask "键的抗拉强度最低要求是多少？"
```

（需配置 API Key 才能完整生成答案）
